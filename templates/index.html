Educational CTF Challenge

Challenge Objective

You've discovered a GraphQL API endpoint that appears to have security vulnerabilities. Your mission is to exploit an Insecure Direct Object Reference (IDOR) vulnerability to access sensitive user data and retrieve the hidden flag.

Goal: Find and extract the CTF flag from the admin user's profile.
